# 어디보자 — iM뱅크 고령자 인앱 음성 안내 에이전트

> 대신 눌러주지 않고, 옆에서 알려줍니다.

**[iM금융그룹] 제4회 대한민국 청년 인재양성 프로젝트** 출품작 데모입니다.

이 사이트는 시연용 **안드로이드 앱(Flutter)과 같은 코드로 만든 웹 빌드**입니다.
화면과 기능은 앱과 동일합니다.

**데모:** https://leehangang.github.io/eodiboja-web/

## 핵심 컨셉
- **타깃**: 창구는 쓰지만 모바일뱅킹 조작이 어려운 고령 사용자
- **원칙**: 거래를 대신 실행하지 않고, 실제 화면 위에 코치마크로 다음에 누를 곳을 **안내만** 합니다.
- **입력**: 또렷한 명령이 아니라, 막혔을 때 무심코 흘리는 혼잣말("이거 어떻게 하지")을 신호로 삼습니다.

## 기능
- **첫 실행 안내** — 우디 소개와 마이크 사용 안내 후 시작
- **2단 처리 구조** — 규칙이 발화를 즉시·오프라인으로 먼저 분류하고, 규칙이 못 잡는 애매한 발화만 생성형 AI(Claude)로 넘깁니다. 안내 말풍선에 `규칙·즉시` / `AI` 배지로 표시됩니다.
- **코치마크 안내** — 홈 → 받는 사람 → 금액 → 확인 → 완료, 계좌이체 흐름의 각 화면에서 누를 곳을 짚어줍니다.
- **다른 화면 개념 안내** — 금액 화면에서 계좌번호를 물으면, 그 내용이 어느 화면에 있는지 알려줍니다.
- **먼저 말 걸기** — 10초간 말도 터치도 없으면 한 번만 "도움이 필요하신가요?"라고 묻습니다.
- **끼어들지 않기** — 도움 요청이 아닌 말에는 반응하지 않습니다.
- **안내 닫기** — 화면을 터치하거나 뒤로 가면 안내가 내려갑니다.
- **인식 기록** — 각 발화가 규칙과 AI 중 어디서 처리됐는지 확인할 수 있습니다.
- **목소리 고르기** — 기기에 설치된 한국어 음성 중 선택하고 미리 들어볼 수 있습니다.

## 사용법
- **Chrome 권장.** 첫 화면에서 "우디와 함께 시작하기"를 누르고 마이크를 허용하세요.
- **설정 열기**: 홈 상단의 `iM Bank` 로고를 **길게 누르면** 설정이 열립니다. 목소리 고르기와 인식 기록도 여기에 있습니다.
- **AI 단계 사용**: 설정에서 Claude API 키를 직접 입력합니다. 키는 코드에 들어 있지 않으며 **이 브라우저에만** 저장됩니다. 키가 없으면 규칙 단계만 동작합니다.

## 웹 버전의 한계
- 음성 인식과 음성 출력은 브라우저 기능을 쓰므로 기기·브라우저마다 동작이 다를 수 있습니다.
- iOS Safari는 음성 인식을 지원하지 않습니다.
- 에코 차단은 네이티브 앱에서 가장 안정적이며, **최종 시연 기준은 안드로이드 앱**입니다.

## 기술
- Flutter (Dart) — 안드로이드 앱과 같은 코드베이스를 웹으로 빌드
- 음성 인식: `speech_to_text` / 음성 출력: `flutter_tts`
- 의도 파악: 규칙 엔진 + Claude Messages API (2단 처리)
- 서체: Pretendard (SIL Open Font License 1.1)
